# simpleconfig

## Simple TOML config loader for Go

**simpleconfig** is a minimal, type-safe TOML configuration loader with zero external dependencies beyond the TOML parser.

```
import "github.com/hrydi/simpleconfig"
```

---

## Quick Start

```go
type Config struct {
	Server struct {
		Host string
		Port int
	}
	Database struct {
		DSN string
	}
}

res, err := simpleconfig.Load[Config](
	simpleconfig.WithFilename("myconfig.toml"),
	simpleconfig.WithCustomPaths("/etc/myapp"),
	simpleconfig.WithValidator(func(cfg *Config) error {
		if cfg.Server.Host == "" {
			return fmt.Errorf("server.host is required")
		}
		return nil
	}),
)
if err != nil {
	log.Fatal(err)
}

fmt.Println("Loaded from:", res.LoadedPath)
```

```toml
# myconfig.toml
[server]
host = "localhost"
port = 8080

[database]
dsn = "postgres://user:pass@localhost/db"
```

## Features

- **Type-safe generics** — `Load[Config]()` returns `*Config`
- **Functional options** — clean API: `WithFilename()`, `WithCustomPaths()`, `WithValidator()`
- **Search priority** — custom paths → `./config/config.toml` → `./config.toml`
- **Returns loaded path** — know exactly which file was loaded
- **Validation hook** — optional `func(*T) error` for custom checks
- **Minimal** — ~100 lines, single dependency (`go-toml/v2`)

---

## Search Priority

1. Custom paths (in order provided) + filename
2. `./config/<filename>`
3. `./<filename>`

## Example: Environment-specific configs

```go
// Load different configs based on environment
var cfg Config
switch env := os.Getenv("APP_ENV"); env {
case "production":
	simpleconfig.MustLoad[Config](
		simpleconfig.WithFilename("config.prod.toml"),
		simpleconfig.WithCustomPaths("/etc/myapp"),
	)
case "staging":
	simpleconfig.MustLoad[Config](
		simpleconfig.WithFilename("config.staging.toml"),
	)
default:
	simpleconfig.MustLoad[Config]() // uses config.toml
}
```
